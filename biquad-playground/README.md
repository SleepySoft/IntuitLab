# Biquad Playground

Interactive FIR/IIR filter teaching playground built with React and Recharts.

## Development

```bash
npm install
npm run dev
```

## Standalone HTML

```bash
npm run build
```

The build produces a single self-contained file at `dist/index.html`. It has no
external script, stylesheet, or asset dependencies and can be opened directly
in a browser without a web server.
